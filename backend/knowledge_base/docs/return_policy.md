# Return Policy

Customers may return most items within 30 days of delivery for a full refund.

## Eligibility
- Item must be in original condition with packaging.
- Proof of purchase (order ID) is required.
- Digital goods and gift cards are non-returnable.

## Process
1. Customer contacts support with order ID.
2. Agent verifies order status via check_order_status.
3. If eligible, agent initiates return or refund.
